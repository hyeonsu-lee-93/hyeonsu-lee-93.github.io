Working memory holds a sequence of items with limited resources, which produces the well-known serial-position effects.
Combining human psychophysics with network models, I proposed that stable and flexible encodings take distinct roles in
retaining and updating information, and that their balance can be controlled to modulate memory performance.
Recently, we applied the same principle to artificial neural networks: a neuromimetic metaplasticity rule that mixes
stable and flexible synapses lets a network learn new tasks without catastrophic forgetting.
